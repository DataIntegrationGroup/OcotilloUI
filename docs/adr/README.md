# Architecture Decision Records

## Convention

- **Filename:** `docs/adr/NNNN-kebab-title.md` — four-digit sequence, **never renumbered**.
- **Status:** one of `Draft`, `Proposed`, `Accepted`, `Rejected`, or `Superseded by NNNN`.
- **Superseding:** a superseding ADR links back to the one it replaces. Superseded ADRs are **kept, not deleted** — the record of why a decision was made and later reversed is the point.
